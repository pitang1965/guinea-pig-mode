# モルモットモード / Guinea Pig Mode

どのウェブサイトにも、かわいいモルモットの相棒を住まわせる Chrome 拡張機能（Manifest V3）です。
[Hedgehog Mode](https://chromewebstore.google.com/detail/hedgehog-mode/pkbjccilodggopgideedpodjalmpbjkl) と同じ発想を、はりねずみではなくモルモットで実装しています。

![GitHubのプロフィールページ上を5匹のモルモットが歩き回り、右側に毛色や匹数を選ぶ設定パネルが開いている画面](docs/screenshot.png)

## できること

- **歩く・走る・寝る・食べる**：画面の下端をうろうろして、たまに寝たりごはんを食べたりします
- **ポップコーンジャンプ**：モルモット特有の、うれしいときにピョコンと跳ねる動きを再現
- **ページの要素の上に乗る**：見出し・画像・ボタンなど、届く高さの要素に自分から跳び乗って、その上を歩きます（スクロールにも追従）
- **ドラッグして投げられる**：つまんで放り投げると、放物線を描いて落ちて着地します
- **クリックでなでる**：ぴょんと跳ねて「プイ♪」と喜びます
- **見た目のカスタマイズ**：毛色6種（茶／アグーチ／クリーム／白／黒／三毛）× アクセサリー7種（お花・リボン・パーティー帽・めがね・王冠・にんじん・なし）
- **ランダムな姿**：毛色・アクセサリーそれぞれに「🎲 ランダム」を選ぶと、**1匹ずつ違う姿**になります。「すがたをシャッフル」でいつでも引き直せます（大きさや速さを変えただけでは姿は変わりません）
- **匹数・大きさ・速さの調整**：1〜5匹まで。複数いるときは互いにゆるく押し合うので、完全に重ならず連なって歩きます（間隔は `main.js` の `PERSONAL_SPACE` で調整）
- **個体差（ばらつき）**：大きさ・歩く速さ・カーソルに気づくまでの反応時間が 1 匹ずつ変わります。0% にすると全員そろい、上げるほど体格も歩調も反応もまちまちになります。体格はそろえ気味に、動きの気質（速さ・反応）は大きく振ってあります（振れ幅は `pet.js` の `SIZE_SPREAD` / `SPEED_RATIO` / `REACT_MAX` で調整）
- **体格に合った歩き方**：移動速度は体高に比例し、歩幅（速度 × 足の周期）は常に体高の約 0.29 倍になります。大きい子は大股でゆったり、小さい子は小刻みに、どの速さでも足が滑りません。走りは歩幅と足の回転で速さを分担します（`pet.js` の `BASE_SIZE` / `GAIT` / `RUN_CADENCE`）
- **キーボード操作**：←→ / WASD で移動、スペースでジャンプ（任意）
- **カーソル追尾**：マウスを追いかけさせることもできます（任意）。反応時間の差で、みんなが一斉には動き出しません
- **サイトごとの無効化**：全体は ON のまま、特定のサイトだけ止められます

すべてブラウザ内で完結します。アカウント不要、外部への通信は一切ありません。

## インストール（開発者モード）

配布用の ZIP は [Releases](https://github.com/pitang1965/guinea-pig-mode/releases/latest) から
ダウンロードできます（`moru-<version>.zip`）。clone した場合はそのまま次の手順に進めます。

1. ZIP でダウンロードした場合は展開する
2. Chrome で `chrome://extensions` を開く
3. 右上の **デベロッパーモード** を ON
4. **パッケージ化されていない拡張機能を読み込む** をクリック
5. このフォルダ（`manifest.json` のある階層）を選択

ツールバーのモルモットアイコンから設定を開けます。
すでに開いていたタブには、リロード後に反映されます。

## 使い方のコツ

| 操作 | 動き |
| --- | --- |
| モルモットをクリック | 跳ねて喜ぶ |
| ドラッグして放す | その勢いで飛んでいく |
| 高い要素の近くに置く | そこから自分で跳び乗ろうとする |
| ポップアップの「プイプイ！と鳴かせる」 | 全員が一斉に鳴いて跳ねる |
| すがたをシャッフル（ランダム選択時） | 全員の毛色・アクセサリーを引き直す |

ジャンプで届くのは足元からおよそ 130px までです。それより高い要素には、つまんで乗せてあげてください。

## 構成

```
manifest.json
icons/                     アイコン（tools/make-icons.mjs で生成）
src/
  shared/settings.js       既定値と chrome.storage ヘルパ（content / popup 共用）
  content/
    character.js           モルモットの SVG を組み立てる（毛色・アクセサリー）
    pet.js                 1匹分の物理・状態遷移・ポインタ入力
    main.js                Shadow DOM ステージ、足場の収集、個体同士の間隔、メインループ
    moru.css               Shadow DOM 内のスタイルとアニメーション
  popup/                   設定 UI
  background/service_worker.js   タブごとの OFF バッジ
tools/                     開発用（アイコン生成・プレビュー・動作確認・配布用 ZIP 作成）
```

ページ側の CSS と干渉しないよう、描画はすべて Shadow DOM の中で行い、
スタイルは `adoptedStyleSheets` で流し込んでいます。
モルモット本体以外はクリックが素通りするので、ページの操作を邪魔しません。

## 配布用 ZIP を作る

```bash
node tools/pack.mjs
```

`dist/moru-<version>.zip` ができます。拡張機能の動作に必要なファイルだけが入り、
`tools/` や `.vscode/` は含まれません。`manifest.json` が ZIP の直下に来るので、
Chrome ウェブストアに出す場合もそのまま使えます。
`manifest.json` が参照しているファイルが欠けていれば、その場でエラーになります。

受け取った人のインストール手順:

1. ZIP を展開する
2. Chrome で `chrome://extensions` を開く
3. **デベロッパーモード** を ON
4. **パッケージ化されていない拡張機能を読み込む** で、展開したフォルダを選ぶ

この方法では自動更新されないので、新しい版を渡したら同じ手順で入れ直してもらいます。

## 開発

```bash
node tools/make-icons.mjs          # icons/*.png を生成（依存パッケージなし）
node tools/serve.mjs               # http://localhost:8765 でこのフォルダを配信
```

サーバを起動した状態で、ブラウザから開きます。

- `http://localhost:8765/tools/preview.html` — 毛色・アクセサリー・各状態の一覧
- `http://localhost:8765/tools/simtest.html` — 物理と当たり判定の自動チェック（全項目 PASS になること）
- `http://localhost:8765/tools/harness.html` — 拡張機能なしで実際に動かす

`simtest.html` は `chrome.*` API をスタブし、`pet.update(dt)` を直接回して
着地・足場の端・投げ・クリック・ヒットテスト・ランダムの姿などを検証します。

## 権限について

| 権限 | 用途 |
| --- | --- |
| `storage` | 設定の保存（`chrome.storage.sync`） |
| `tabs` | ポップアップで現在のサイト名を表示し、「このサイトでは表示しない」を切り替えるため |
| `<all_urls>`（content_scripts の `matches`） | どのページでもモルモットを表示するため。`host_permissions` は使っていません |

収集・送信するデータはありません。
